# Extension Ikoner

For at bruge extension'en skal du tilføje ikoner i følgende størrelser:

- `icon16.png` - 16x16 pixels
- `icon48.png` - 48x48 pixels
- `icon128.png` - 128x128 pixels

## Sådan laver du ikoner

### Online værktøj (nemt)

1. Gå til [Favicon Generator](https://favicon.io/)
2. Vælg "Text" eller upload et logo
3. Design dit ikon med "✨" emoji eller "SS" tekst
4. Download og omdøb filerne til `icon16.png`, `icon48.png`, `icon128.png`
5. Placer dem i denne mappe

### Canva (gratis)

1. Gå til [Canva](https://www.canva.com/)
2. Opret et 128x128px design
3. Tilføj tekst "SS" eller "✨" ikon
4. Download som PNG
5. Resize til 16px, 48px og 128px versioner

### Photoshop/GIMP

1. Opret nyt dokument 128x128px
2. Design dit ikon
3. Gem som PNG
4. Opret resized versioner (16px og 48px)

## Placeholder ikoner

Indtil du tilføjer rigtige ikoner, vil extension'en fungere, men ikoner kan være tomme i browser UI.

## Anbefalet design

**Farver:**
- Primær: `#4F46E5` (Indigo)
- Baggrund: Hvid eller transparent

**Style:**
- Minimalistisk
- Modern
- Let genkendelig
- Virker i lille størrelse

**Forslag:**
- "SS" initialer
- ✨ Sparkle emoji
- 🎨 Paint palette
- Modern abstrakt form
