# 🚀 Quick Start Guide

Kom i gang med Spy Systems Modern UI på 5 minutter!

## 📦 Installation (3 steps)

### Step 1: Download
```bash
git clone https://github.com/jonasraaschou-afk/Spy-Systems.git
```

### Step 2: Åbn Chrome Extensions
1. Åbn Chrome
2. Gå til `chrome://extensions/`
3. Tænd **Developer mode** (øverst til højre)

### Step 3: Load Extension
1. Klik **Load unpacked**
2. Vælg `Spy-Systems` mappen
3. ✅ Færdig!

## 🎯 Brug det

1. **Gå til Spy Systems** i din browser
2. Se den automatisk få moderne styling! 🎨
3. Klik på **extension ikonet** for indstillinger

## ⚙️ Indstillinger

**Klik på extension ikonet** i Chrome toolbar:

- ✅ Tænd/sluk modern UI
- 🌙 Aktiver dark mode
- 🎨 Vælg farvetema
- 🔄 Genindlæs siden

## 🎨 Tilføj Ikoner (valgfrit)

Extension virker uden ikoner, men de gør det pænere:

1. Gå til [Favicon.io](https://favicon.io/)
2. Generer ikoner (brug "✨" eller "SS")
3. Download og omdøb til:
   - `icon16.png`
   - `icon48.png`
   - `icon128.png`
4. Placer i `icons/` mappen
5. Reload extension i Chrome

## ❓ Problem?

**Extension vises ikke?**
- Tjek at developer mode er aktiveret
- Klik reload på extension i `chrome://extensions/`

**Styling virker ikke?**
- Genindlæs siden (F5)
- Åbn extension popup og tjek at "Aktiver Modern UI" er tændt

**Andre problemer?**
- Se [README.md](README.md) for fuld dokumentation
- Åbn Developer Tools (F12) og tjek console for fejl
